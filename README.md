# Nourvanda Portfolio

A colorful, responsive personal portfolio focused on frontend development, with animated programming symbols.

## Run locally
1. Extract this ZIP.
2. Keep `index.html`, `style.css`, `script.js`, and `nourvanda-photo.jpeg` in the same folder.
3. Open `index.html` in a browser, or use VS Code Live Server.

## Before publishing
- Check all project links and update any that need a different destination.
- The portrait is stored locally as `nourvanda-photo.jpeg`.
- To publish with GitHub Pages, push the files to a repository and enable Pages from the repository settings.
